# 正式实验结果与研究判断

日期：2026-09-21。所有工程数值均为假设模型预测；没有实体或有限元验证。

**420 次正式运行已全部完成，但现有“耳切 + 型号分层档案”组合尚未证明比基础 MODE 更好。有限候选集压缩有所改善，与完整优化搜索的收益必须分开表述。**

## 实际执行与审计

- 7 方法 × 3 个周期上限（2.5/3.0/3.5 s）× 20 配对种子；64 个体、500 代，初始评价计入预算。
- 每次 32,064 次设计评价，合计 **13,466,880 FE**；每次包含 9 个情景。
- 批次执行日志记录 **374.5 s**，低于已批准的 1,800 s 上限。没有更换种子、补跑寻优或改变冻结算法。
- 420 个 MAT、840 个结果/轨迹 CSV 齐全。全部源文件和协议的 28 项冻结哈希一致。
- 26,880 个最终设计重新评价，目标与 CV 差值均为 0；这是额外的结果审计，不计作另一轮优化。Python 独立复算 HV 的最大差为 9.99e-16。
- 所有最终可行点都在预设 HV 参考范围内。419 次运行的最终种群全部可行；CAT-QMC 在 2.5 s/种子 93111 下为 63/64 可行，其不可行点已从 HV 和工程终点中排除。

证据：`analysis_audit.json`、`model_reevaluation_audit.json`、`raw_hashes.csv`、`../provenance/formal_execution_captured_20260921.log`。MATLAB MCP 捕获了完整命令窗口输出；原 diary 文件为空，故以原样保存的 MCP 输出作为执行日志，不把空文件当作证据。

组合在 2.5 s 工况优于 MV-NSGA-II、MV-SPEA2 和 CAT-QMC；在 3.0/3.5 s 工况，仅对 CAT-QMC 达到本协议的校正显著性阈值。它没有显著优于任何 MODE 消融版本。故不能把相对 QMC 或遗传算法参考实现的收益归因于新增 A/B 机制。

## 消融与机制诊断

- A（耳切）、B（分层档案）以及 A×B 交互的九项效应均未达到各工况三项 Holm 校正后的 0.05 水平；完整数值见 `factorial_effects.csv`。
- 2.5 s 工况中，B 与交互各有 13/20 个种子效应为零，四种 MODE 的最终档案型号数中位数均为 1。这与严格工况下可供分层的型号空间很小相符。
- 3.0/3.5 s 工况，分层档案保留的型号数中位数为 5/7，全局档案对应约 1–1.5/3。分层机制确实改变了搜索记忆，但尚未转化为显著 HV 收益。
- 组合在宽松工况的 HV 标准差较基础方法小，是描述性线索；本轮没有预设并证实方差或失败概率改善，不能改称“可靠性已显著提高”。

|周期上限|基础 MODE|组合方案|

|2.5 s|2.288012 s|2.288363 s|
|3.0 s|2.295615 s|2.294727 s|

这组结果没有显示组合方案一致缩短节拍。在 2.5 s 限制下，两者均未找到满足 0.05 μm 阈值的设计（0/20）；这不构成不可行性证明。阈值只是预设数值比较量，不是实测定位精度。

`best_found_engineering_designs.csv` 另列出各工况、各阈值下从**全部保存运行**中找到的 8 组最短周期候选，包含型号、T/r/u、来源方法和种子，以及转速、转矩/变形/额定寿命筛选值。8 组均为 BTK2510V-5.3；目录转速是最接近的约束。例如，2.5 s 工况、0.1 μm 阈值的候选预测周期 2.284303 s，残余包络 0.099850 μm，来自 MV-NSGA-II/93119。它不是全球最优性证明，也不能用“跨方法、跨种子选出的最好单点”重新排名算法。`selected_trajectory.png` 给出一个已标明来源的 3.0 s 工况候选轨迹。

## 事后有限前沿压缩诊断

使用已经保存的可行设计构成三个候选池，将每池分别压缩到 64 点。没有新增目标函数评价。这里的候选池汇集了多方法、多种子，以及允许时更严格工况的已有点，因此**不是又一个同预算优化器对照，也不是已知精确 Pareto 前沿**。

|工况|池内非支配点|单次 CD 的 HV|有覆盖界耳切的 HV|迭代 CD 的 HV|
|---|---:|---:|---:|---:|
|2.5 s|530|0.960072|0.960945|0.960874|
|3.0 s|936|0.976485|0.981767|0.981743|
|3.5 s|1,254|0.951215|0.984861|0.984812|

耳切相对单次 CD 改善了大候选池的压缩结果，但 HV 与迭代 CD 非常接近，且这三池的覆盖半径均不如迭代 CD。因而更准确的结论是：**耳切的候选集压缩能力可以观察到，但尚未成为完整 MODE 搜索优势。** 不能省略迭代 CD 这个强对照。

另一个结构检查是可行域嵌套：放宽周期上限只放宽周期约束，真实可达 HV 不应下降；然而多数方法的 3.5 s 运行中位数低于 3.0 s。汇总未压缩可行池的 HV 随周期上限递增，说明中位数下降反映有限预算搜索/保留困难，不能解释为更长允许周期导致物理设计变差。单次 CD 对大池的再压缩本身也可能损失较多 HV。

## 协议实现限制与下一步

1. 每代耳切调用、回退次数和最大覆盖界超差有记录，**绝对覆盖半径的逐代序列未保存**。这项次要日志未完整实现，不能事后伪造；主要 HV/消融分析不依赖它。
2. QMC 的累计可行率/未压缩档案大小与 MODE 的种群指标含义不同，未将它们混作同一种曲线比较。
3. 本轮不支持把“耳切 + 多机制叠加性能更强”作为论文主结论。下一阶段应针对“大档案压缩”或“宽可行域中有效候选的持续保留”提出可证伪方案，并纳入迭代 CD；不能继续无目标地叠加算子。
4. 已批准的 420 次运行全部完成，未自行启动新一轮优化。后续研究方案需有明确机制理由、对照与预算；现有负结果完整保留。
5. 论文已按正式结果修订为数值方法评估稿，尚缺充分的新颖性差异及当前中科院分区核验，不能保证录用。
