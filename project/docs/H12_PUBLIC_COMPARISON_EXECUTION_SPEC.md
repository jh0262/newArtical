# H12 公开比较执行规格

H12 将 H11 的单问题接入推进为“问题定义、算法来源、类型编码和 NFE 记账”四条证据链的联合验证。完整科学问题、估计量和失败树见 `.light/h12/`。

## 冻结范围

- 问题：RCM06、RCM19、RCM25。
- 内部算法：B5S、B1、N2。
- 官方算法：PlatEMO v4.15 NSGA-II、CCMO(type=GA)。
- 当前运行：每组合 `N=12`、`NFE=36`、seed `12025` 的接口烟雾测试。
- 禁止：据烟雾测试排序算法或宣称性能优越。

## 新发现的排除证据

RCM29 不进入 H12：论文式(71)的 `f1` 包含连续项 `(1-x1)^2+(2-x2)^2+(3-x3)^2`，官方 `CEC2021_func.m` 的 `f1` 只含二元项和对数项；代码还使用 `log(abs(1+x7)+1e-6)`。在作者版本决策前，两者不能静默合并。

## 执行判据

1. 适配器与官方快照在冻结点逐项误差 `<=1e-10`。
2. 每个算法实际 evaluator calls 精确等于 36。
3. 所有连续/有序整数/二元变量合法，目标和约束无 NaN/Inf。
4. 同 seed 结果可重放；外部 PlatEMO 调用不污染调用者 path 和 RNG。
5. 全回归和静态检查通过。

满足这些条件只代表 H12 执行链可用于后续正式实验，不代表任何算法效果结论。
