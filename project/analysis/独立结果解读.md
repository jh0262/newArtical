# PADE-FE v4 完整结果的独立解读

日期：2026-10-15。读取`POSTPROCESS_READY.json`确认稳定矩归约完成后，独立读取全部5640次运行的CSV、136个完整预设比较、工程回代JSON及独立运行审查。使用`independent_result_extract.py`复算摘要与活动比例，来源哈希保存在`independent_result_extract.json`。未运行优化器、调整参数或删除样本。

**主要判断：同父、同实际FE和核心消融已经补齐，但结果没有支持PADE新增机制带来稳定性能增益。相对经典DE的优势仍然存在；它与相对同父ADE没有优势、并在部分问题上退化的结论必须同时写清。** 这改变的是贡献归因和投稿主张，不改变原始数据真实、代码能够实际运行这一前提。

## 1. 六个预设家族

计数依次为“新增/完整方案显著更优—未检出差异—对照显著更优”，全部使用原预设家族内Holm校正。

| 家族 | 结果 | 独立解释 |
|---|---:|---|
| 完整PADE vs ADE-Parent | 0—20—6，26题 | 核心增量性能主张未获支持；有6项不利差异 |
| 完整PADE vs CLASSIC_DE | 14—12—0，26题 | 整体方案较固定参数DE有优势；14胜为F01—F13及CB，CB属于很小数值差 |
| 谱尺度增量G2 vs G1 | 0—22—4，26题 | 本轮谱缩放没有建立正增益，在F01/F03/F04/F05出现不利效应 |
| 主轴交叉增量G1 vs G0 | 0—23—3，26题 | 在P开启背景下，主轴交叉未建立正增益；F04/F09/F10不利 |
| 脉冲P增量 | 0—26—0，26题 | 触发和局部接受确实发生，但未形成家族内终值优势 |
| PV普通trial抖动J | 0—6—0，6对 | 观察到小幅均值下降，未检出稳定成本优势 |

这里的20或26项“未显著”不改称等效。关键是本轮预设主要问题“比同父算法增加这些机制是否更好”没有得到阳性答案。相对经典DE的14胜不能替代这一问题。

## 3. 机制解释应从“设计正确”转为“当前实现的实际作用”

谱尺度的负效应在F03/F04/F05最清楚：G1的Mean分别为0.0671699、0.575377、20.07823，加入谱比例后的G2分别变为42.39818、5.310525、32.71517。这一对照直接表明，在当前门、父算法及预算下，所用谱比例并未改善这些问题。精英协方差是群体形状代理，不能仅由低方差或曲率术语推出缩小相应方向就是有效修正。

主轴交叉在F04的Mean由G0的0.267705升至G1的0.575377；F09由2.16737e−4升至5.66939e−4；F10的G1又有一次0.9313残留。这说明方向变换也具有负干预条件。其余问题未检出差异，不能从本轮结果宣称“普遍几何增益”。

完整方案应正确选取25个连续问题的G2P1J0和PV的G2P1J1，共780次。不能把PV的G2P1J0又计入完整方案，造成810次的错误汇总。

- 完整方案37/780次运行触发P，累计136批、968个脉冲评价、121次接受、6次改善当时最优；pulse占完整方案25224300总FE的约0.00384%。这证实P确实运行且非常稀疏。
- 改善当时最优不等于改善共同预算终值。P家族26题均未显著；F15改变了11对终值，其中2好9差，未校正p=0.0703125，不能描述成确定的正收益。
- 完整方案共有3013970个主轴trial，占普通trial约11.96%。P稀疏不意味着所有新增操作都稀疏。
- PV中主轴trial为0；P消耗608 FE，但0接受、0次改善最优。该问题的几何门自然关闭，不能用PV结果实证几何模块的收益。
- PV的J影响1155737个候选，约占普通trial的38.53%；有1316288次有效坐标改变，1437个带J候选被接受，候选接受比例约0.124%。网格动作的确活跃，终值收益仍需由比较决定。

PV的六个J比较得到相同终值差、10胜13同值7负和名义p=0.478897；这些不是六次独立重复证明，而是在本问题几何门关闭、P未接受背景下产生的相同观测关系。

### 常量样本Std=0的数值修正

新WB以及自适应CB的30个raw终值逐位相同，按样本标准差定义应为0。普通归约曾产生均值略低于Best以及1e−15级Std；后处理改为先减固定样本锚点，再计算均值和Std，恢复常量样本的精确零离散性。这是数值归约修正，原始f、CV、种子、检验秩和p值没有改变。旧稿的原表报值独立保留。

## 5. 更新后的创新性与发表潜力判断

四类失配到有限介入的设计链、明确条件恢复及统一实现仍有方法分析价值。本轮尤其补上了此前缺失的贡献归因：完整PADE比固定参数DE更好，并不意味着所增加的几何与恢复动作比其自适应父算法更好。新结果显示，当前谱尺度与部分主轴使用产生了负干预，双锁P与J尚未提供家族内显著收益，两个连续工程问题的最终表现由父算法同样达到。

因此，**当前版本不足以按“新增机制提升优化性能的新算法”这一主张直接投稿**。这不是以更多形式要求否定研究，而是主比较已经给出明确答案。相较上一轮“中等创新、大修后投稿”的判断，方法型性能论文的发表依据应下调：关键实验补齐后，原中心优势主张仍未成立。

若据本轮结果定稿，最自洽的方向是几何与状态介入的有效边界及负干预机制研究，突出同父、同FE和活动记录共同揭示的结果；它需要以这些真实发现组织讨论，而不是把结论措辞略降后继续暗示全面提升。保留作者“先诊断病灶、再有限介入、可条件恢复”的研究主线，同时承认目前所实现的处置尚未建立预期收益。后续算法开发应另设开发与验证阶段，本轮冻结配置和全部阴性结果保持不变。
