# Research Brief

## Research objective

以旧稿《基于差分进化算法的滚珠丝杠传动多目标优化》为研究种子，重建一个物理一致、可复现、证据边界明确的滚珠丝杠传动“算法 + 模型优化”SCI期刊论文。研究对象、模型层级和算法创新将在文献核验与先导实验后冻结。

## Input

- 原始旧式 Word 稿及其 SHA-256 哈希。
- 原稿中可恢复的目标函数、约束、HMOPSDE 思路、ZDT 测试设置和引用线索。
- 本地文献知识库中的滚珠丝杠接触、结构优化、可靠性、代理模型和差分进化论文。
- 可在线核验的近期论文、标准、制造商技术资料与期刊要求。
- 本项目新生成的代码、配置、随机种子、日志和结果文件。

## Output

- 冻结的研究问题、假设、变量、目标、约束、单位和验证方案。
- 可复现的滚珠丝杠性能模型与优化算法实现。
- 基线比较、消融、敏感性、统计检验和工程算例结果。
- Claim-Evidence 矩阵、参考文献核验表、图表与审计报告。
- 使用 OfficeCLI 编辑并通过结构、引用、公式、视觉和投稿前检查的英文 DOCX 论文。

## Process

源稿取证与污染边界识别 → 本地与在线文献核验 → 候选研究问题与先导实验 → 冻结模型和算法 → 测试驱动实现 → 数值验证与模型校核 → 同预算算法实验 → 统计、消融和敏感性分析 → 英文论文写作 → OfficeCLI 结构化编辑 → 引用、声明、视觉和投稿前审计。

## Flow logic

初始化并绑定源文件哈希
→ 分离研究正文与模板示例
→ 构建文献证据矩阵
→ 生成候选算法-模型组合
→ 以新颖性、物理可解释性、可验证性和实验成本排序
→ 自动选择通过门槛的首选方案
→ 冻结变量、公式、单位、约束、评价预算和随机种子
→ 先写单元测试与解析基准
→ 实现高保真/解析模型和代理模型
→ 实现基线及改进算法
→ 运行小规模 sanity check
→ 运行完整重复实验
→ 检查失败、可行率、收敛与统计显著性
→ 将结果绑定到论文 claim
→ 形成英文稿、图表和补充材料
→ OfficeCLI 编辑、渲染和交付门检查。

## Initial evidence status

- 已知：源文件为 OLE `.doc`，转换副本含 171 段、6 表、60 个 OLE 对象。
- 已知：相关正文描述体积最小与效率最大、9 个非线性约束、HMOPSDE 和 ZDT 测试。
- 已知：源文档后半含量化器、天然气发动机和隧洞等模板示例，不能作为研究证据。
- 待核验：OLE 公式、原算例数据、HMOPSDE 原始结果和原引用元数据。
- 待冻结：最终研究对象、模型层级、算法名称、目标函数和期刊。
