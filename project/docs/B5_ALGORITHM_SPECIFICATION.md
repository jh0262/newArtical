# B5：评价均衡混合离散约束多目标差分进化

## 建议题目

中文：**面向断裂可行域的评价均衡混合离散约束多目标差分进化算法**

英文：**Evaluation-Balanced Mixed-Discrete Constrained Multiobjective Differential Evolution for Disconnected Feasible Regions**

## 输入

- 混合决策向量：连续、整数、序数和类别变量；
- 变量边界、类别集合与黑箱目标/约束评价器；
- 种群规模 N、评价预算、DE 参数 F/CR、类别供体概率；
- 固定离散注入率 η=0.05。

## 输出

- 有限外部非支配档案；
- AUC_PCR、最终 PCR、HV、IGD+、mIGD+、可行率、重复率；
- 离散状态访问计数和逐代注入数量审计。

## 核心流程

```text
初始化混合表型种群并评价
  ↓
累计每个已评价离散配置的访问次数
  ↓
类型保持 DE 生成后代
  ↓
选择 ceil(0.05N) 个后代行
  ↓
用当前访问次数最少的离散配置替换其离散块
  ↓
评价后代并更新访问计数
  ↓
可行性优先非支配排序 + 拥挤度环境选择
  ↓
更新外部档案与生命周期分量覆盖记录
  ↓
达到评价预算后输出
```

## 科学针对性

断裂可行域中的核心困难并非仅是“解的目标空间分布不均”，而是部分离散配置在有限预算内长期未被评价。B5 将搜索状态从种群成员扩展为“离散配置的累计评价暴露”，以最少访问原则直接控制评价机会分配。它不估计真实连通分量，也不需要可行标签，因此避免了早期错误分区被永久保护的问题。

## 复杂度

令离散配置总数为 Q，注入数 `k=ceil(0.05N)`，决策维数为 D。

- 类型保持 DE：O(ND)。
- 访问计数更新：当前实现为 O(N+Q)。
- 最少访问注入：当前实现对每个注入项排序 Q 个状态，最坏为 O(kQ log Q)。
- 访问计数内存：O(Q)。
- 环境选择和档案为各算法共用成本；当前确定性非支配排序实现的最坏复杂度高于原始 NSGA-II 的 O(MN²)，因此本项目运行时间不用于理论优越性主张。

这意味着 B5 适合 Q 可枚举或中等规模的问题。若 Q 随离散维度指数增长，显式计数表将成为主要限制；后续应研究稀疏哈希计数、优先队列或分解式状态覆盖，而不能把当前实现外推到超大组合空间。

## 已验证与未验证

已验证：程序不变量、类型保持、真值隔离、H5/H6/H7 自建解析实例上的配对统计、机制消融和总体非劣。

未验证：公共 CMOP 套件、PlatEMO 官方算法实现、超过 NSGA-II 之外的现代 CMOEA、工程模型、高维不可枚举离散空间、真实计算成本受限优化。
