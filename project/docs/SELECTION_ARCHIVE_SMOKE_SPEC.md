# Shared Environmental Selection and Archive Smoke Specification

状态：`FROZEN_FOR_SOFTWARE_SMOKE / NOT_CONFIRMATORY`

## 1. 研究边界

本阶段只补齐 B0/B1 共用的：

1. 可行性优先的环境选择；
2. 可行非支配有限外部档案；
3. 多代 NFE、累计 PCR 与档案状态记录；
4. 固定实例、固定种子、短程五代软件 smoke。

本阶段不实现 B2 普通 niching、B3 oracle 分量保护、B4 在线分量估计，不进行参数调优、多种子随机性估计、假设检验或正式性能比较。

## 2. 公平比较常量

B0/B1 必须共享：

- 初始表型种群；
- 每代供体索引、交叉掩码及随机数调度；
- 种群规模、NFE 预算和代数；
- 约束违反量定义、环境选择、档案容量和输出字段。

两分支种群在第一代后允许因离散后代和环境选择而分化，因此第二代起不要求连续后代数值相同；公平性由共享调度及相同评价预算保证。

## 3. 约束违反量

对候选 (i)，定义

\[
CV_i=\max(g_{i1},0)+
\frac{\max(g_{i2},0)}{0.5-\rho}.
\]

当 \(\rho=0.5\) 时第二项恒为零。该归一化只用于不可行候选之间排序，不改变可行判定 \(g_j\le0\)。

## 4. 环境选择

输入为父代和后代合并集，输出固定大小 (N) 的下一代：

1. 任一可行候选优先于任一不可行候选；
2. 可行候选按双目标最小化非支配层排序；
3. 完整非支配层依次进入下一代；
4. 临界层按 NSGA-II 归一化目标空间拥挤距离降序截断；
5. 可行候选不足时，不可行候选按归一化 (CV) 升序补足；
6. 所有平局均按目标值、表型的字典序确定，不使用输入行号作为科学判据。

选择器不得读取真实连通分量标签、PCR 或历史命中信息。

## 5. 有限外部档案

档案输入为旧档案和本代新评价候选：

1. 只保留可行候选；
2. 同一表型只保留一份；同表型若对应不一致目标值或约束值则立即失败；
3. 只保留合并集中的非支配候选；
4. 超过容量时按目标空间拥挤距离降序截断；
5. 容量固定为 (A=N=30)；
6. 档案不参与本阶段的供体选择，只作为有限输出状态。

档案不使用真实分量标签，因此不是 B3 oracle 档案。

## 6. 累计诊断与 NFE

- 初始种群评价后 NFE 为 (N)；
- 每代每分支新增 (N) 次评价；
- 五代 smoke 的每分支最终 NFE 为 (6N=180)；
- 检查点为 (0,N,2N,\ldots,6N)；
- PCR 使用截至检查点的全部已评价候选重新计算，而不是只用当前种群或有限档案；
- 因此累计 PCR 必须单调不减；
- PCR-AUC 只作为诊断管线追踪值，不在本阶段解释算法优劣。

## 7. 固定 smoke 配置

- 实例：D，(q=3,L=3,\rho=0.15,\lambda=1)；
- (N=30,A=30,G=5)；
- seed：20260829；
- (F=0.5,CR=0.9,F_c=0.5)；
- 第 (g\) 代调度种子为 `seed + g`；
- MATLAB：CPU、双精度、局部 `RandStream('mt19937ar')`；
- 两次独立运行目录必须保留相同配置和原始逐候选记录。

## 8. 必须保留的原始证据

- 配置、环境、源码哈希指针和运行清单；
- 初始种群及每代共享调度；
- 每个分支的全部已评价候选、每代选择后种群和最终档案；
- 每个检查点的 NFE、PCR、重复率、两类约束无效率、档案规模；
- stdout、stderr 和失败清单。

## 9. 失败条件

- 可行候选被不可行候选越级替代；
- 临界层截断不确定或对输入行置换敏感；
- 档案含不可行、被支配或重复表型；
- 档案超过容量或读取真实分量标签；
- B0/B1 的 NFE、代数、调度对象或档案容量不一致；
- 累计 PCR 下降；
- 同固定 seed 两次 smoke 的确定性原始文件不同；
- 任一 NaN、Inf、越界表型或缺失运行证据。
