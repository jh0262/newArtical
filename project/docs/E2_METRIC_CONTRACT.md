# E2 Quality-Metric and First-Hit Contract

状态：`FROZEN_FOR_DETERMINISTIC_METRIC_VERIFICATION / E2_NOT_RUN_READY`

## 1. 证据边界

本合同只冻结并验证 E2 所需的二维 HV、IGD+、分量等权 mIGD+、Pareto 相关分量首次命中 NFE 和参考前沿离散化。它不授权 P1/P2 多种子运行，不把任何既有 smoke 数值纳入确认性分析。

## 2. 通用约定

- 所有目标均为最小化；
- MATLAB CPU `double`；
- 输入出现 NaN/Inf、形状不匹配或非法 NFE 时间轴时立即失败；
- 浮点测试容差：`AbsTol=1e-12`，性质测试不得依赖浮点逐位相等；
- 行置换不得改变 HV、IGD+ 或 mIGD+；
- 重复目标点不得改变指标；
- 指标只评价，不参与后代生成、环境选择或档案更新。

## 3. 二维可行 HV

参考点固定为

\[
\mathbf r=(1.1,1.1).
\]

HV 输入为最终外部档案的可行非支配目标点。实现仍需自行去除重复点、被支配点及不严格优于参考点的零贡献点。空集合 HV 定义为 0。二维精确面积使用矩形并集，不使用 Monte Carlo 近似。

## 4. IGD+

对参考点 \(\mathbf z\) 和近似点 \(\mathbf a\)，最小化问题的单向距离为

\[
d^+(\mathbf z,\mathbf a)=
\sqrt{\sum_m \max(a_m-z_m,0)^2}.
\]

\[
IGD^+(A,R)=\frac{1}{|R|}\sum_{\mathbf z\in R}
\min_{\mathbf a\in A}d^+(\mathbf z,\mathbf a).
\]

参考集非空。若运行没有可行档案，核心函数返回 `Inf`；E2 结果文件同时记录 `metric_status=NO_FEASIBLE`，统计输入使用虚拟近似点 `(1.1,1.1)` 计算的有限失败惩罚，并保留原始 `Inf` 状态，禁止静默丢弃该运行。

## 5. 分量等权 mIGD+

对每个真实 Pareto 相关分量 \(k\) 的参考子集 \(R_k\)，使用完整可行档案 \(A\) 计算

\[
mIGD^+(A)=\frac{1}{K_P}\sum_{k=1}^{K_P}IGD^+(A,R_k).
\]

每个分量权重相同，不因参考点数量或分量弧长增大而增加权重。真实分量标签只用于已知真值基准的离线诊断，不进入算法选择。

## 6. 参考前沿

- 每个 Pareto 相关分量生成 101 个等距参数点；
- 分量区间由 `truth.paretoSegments` 中属于该分量的区间并集外包络 `[min(lower), max(upper)]` 给出；
- 参考目标点为 `(p,1-p)`，包含两端点；
- 输出每个参考点的真实分量 ID；
- 每个相关分量必须恰有 101 点。

## 7. 首次命中 NFE

候选按实际评价顺序给出严格递增的正整数 NFE。候选在到达时若：

1. 满足全部约束；
2. 在截至该候选的已评价可行集合中非支配；
3. 属于真实 Pareto 相关分量；

则该分量首次命中时间记为当前 NFE。未命中分量在固定预算 `B` 处右删失，输出 `time=B`、`eventObserved=false`，不得用 `B+1` 冒充实际观察。

## 8. E2 使用位置

- 主指标：累计 `AUC_PCR`；
- 主要时间点：固定预算 `B=500N`；
- HV、IGD+、mIGD+：最终档案上的次要指标；
- 首次命中 NFE：分量级删失结果；
- 无可行解、预算耗尽、指标非有限或源码哈希不匹配均保留为失败/guardrail 证据。

## 9. 验证失败条件

- 人工可算二维 HV 或 IGD+ gold 值不一致；
- 增加非支配点导致 HV 下降；
- 行置换或重复点改变指标；
- mIGD+ 被分量参考点数量隐式加权；
- 参考前沿每分量点数不等；
- 首次命中把不可行、被支配或 Pareto 无关分量计为事件；
- 未命中分量未正确右删失；
- 任一原有 39 项测试回归失败。
