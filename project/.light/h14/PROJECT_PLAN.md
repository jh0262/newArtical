# H14 SparseLedger 机制与边界研究计划

版本：v0.2（2026-08-31，pre-data H4/analysis amendment）  
状态：已获 H4 计划修订与统计分析编码授权；正式性能实验未授权。

## 科学问题与 estimand

H13 已观察到 B5S 相对 B1 在三个公开问题上均无显著终点优势，同时在 RCM25 上相对 CCMO/N2 失败。H14 不把这些事后结果改写为普适结论，而是提出可证伪问题：在离散状态数增大、可行状态沿序数轴分散时，SparseLedger 的“最少访问状态注入”是否比同频率的均匀随机注入产生更高的可行离散状态覆盖 AUC，并且不损害终点归一化可行 HV。

主 estimand 是景观实例层面的配对差：先在同一景观、同一算法 seed 下计算 B5S−B5R 或 B5S−B1 的可行离散状态覆盖 AUC（FSCAUC）差，再对每个景观的 10 个配对 seed 取均值，最后在 16 个独立景观上推断。seed 是景观内随机重复，不是独立推广单位。

## Input

- 冻结因子：Q={16,256,4096}，状态布局={connected,dispersed}，每个可行状态的连续可行分量 L={1,4}；边界组 Q=2。
- 冻结算法：B1、B5R、B5S；三者使用相同初始种群、NFE、种群规模、DE 参数和算法 seed。
- 景观 seed 16 个，算法 seed 10 个；解析评估器，不使用工程数据或物理实验。
- H7 既有 HV 非劣界 −0.005 仅作为项目内 guardrail，不宣称为外部验证的 SESOI。

## Output

- 受控断裂可行域基准生成器、算法不可见的指标 oracle、模型断言和单元测试。
- 预注册式实验矩阵、目标链、失败树、风险账、复现清单和授权边界。
- 获得后续单独授权后，输出 6720 个正式 run bundle、源代码/种子/环境 manifest、景观聚类统计和 claim-evidence 表。

## Process

1. 生成含一个序数离散变量和四个连续变量的解析基准。
2. 把 Q/4 个可行状态排成相邻块或等间隔孤立状态；Q=2 仅保留一个可行状态。
3. 每个可行状态布置 1 或 4 个互不相交的连续球形分量；目标锚点按分量顺序铺设互不支配前沿段。
4. 仅由指标观察器持有 allowed-state、center 和 component 标签；优化器只接收变量范围与 `(obj,con)` 评估器。
5. 先做解析断言、随机流隔离、truth firewall、B5R 单变量消融和小预算 smoke。
6. 正式授权后按冻结矩阵运行；失败可恢复但不得静默丢 run。
7. 在景观层面做 cluster bootstrap、Holm 校正和 HV guardrail 判定；按预写成功/失败/无结论分支报告。

## Flow logic

计划冻结 → 生成景观 → 验证状态拓扑/分量间距/前沿不支配性 → 构造三算法同 seed 配对 → 10,000 NFE 固定预算运行 → 每 100 NFE 记录覆盖 → seed 内配对并汇总到景观 → 16 个景观推断 → Holm + HV guardrail → 支持、反证或无结论 → 仅在新授权下扩展。

## 模型假设与可证伪性

- 离散变量是序数状态；connected/dispersed 只改变可行状态在序数轴上的拓扑，不改变可行状态比例。
- 连续分量是半径 0.20 的四维球；同一状态内中心距离严格大于 2r。解析总体可行率约为 L=1 时 0.197%、L=4 时 0.790%，在 10,000 NFE 下对应约 20/79 次均匀命中；仍属稀疏可行域，但避免主指标近乎全零。
- 解析目标把每个分量映射为宽度 `1/(K L)` 的前沿段；预检必须确认采样端点不存在严格支配。
- H1：Q=4096、dispersed 下 B5S 相对 B5R 的景观层 FSCAUC 差下界大于 0.01 且通过 HV guardrail。
- H2：同一单元 B5S 相对 B1 的景观层 FSCAUC 差下界大于 0.01 且通过 HV guardrail。
- H3：B5S−B5R 的 FSCAUC 增益在 Q=4096 比 Q=16 至少高 0.01。
- H4：Q=2 仅作为次要伤害检测边界；B5S 相对 B5R、B1 的终点 HV 不应明确劣于−0.005，但不得由“不显著”推断等效。
- 反证条件和无结论分支见 `failure-tree.json`；任何失败均禁止继续写普适优越性。

## 对照公平与消融隔离

B5R 是关键单变量消融：它与 B5S 使用相同注入代数、注入比例、替换行选择种子、种群选择和评估预算，唯一变化是离散状态目标由“SparseLedger 最少访问”改为“全状态均匀随机且当代不重复”。B1 不做 novelty injection，用于估计整个注入机制相对常规混合 DE 的总效应。所有方法使用相同 evaluator、N=100、archive=100、10,000 NFE、景观和算法 seed。调参预算为 0。

## 指标与分析

Primary：FSCAUC，按累计发现的真实可行离散状态数/K 归一化，在 NFE=0,100,...,10000 上作梯形积分并除以总预算。算法不读取真值；评估后的 observer 才把可行 state 计入曲线。

Secondary：连续分量覆盖 AUC、终点归一化可行 HV、首次可行 NFE、重复状态提议率、运行时间。终点 HV 仅作质量 guardrail 和次要结论，不替代覆盖机制指标。

统计家族含 H1–H3 三个 primary contrast，Holm FWER=0.05。0.01 absolute FSCAUC 是本计划采用的最小机制效应阈值。景观是唯一独立分析单位；每个景观内 10 个 paired seeds 与 L={1,4} 先求均值，再计算16个景观的算术平均效应。每个主效应使用20,000次固定种子的景观重采样生成双侧95% percentile CI，并对 `effect−0.01` 做16个景观的单侧精确符号翻转检验；三项原始 p 值经 Holm 调整。H1/H2 的 B5S−baseline HV 按相同景观聚合与 bootstrap 计算，CI 下界必须 >=−0.005。

H4 不进入 Holm 主比较族。Q=2 下分别计算 B5S−B5R 与 B5S−B1 的终点 HV 景观 bootstrap CI：两者下界均 >=−0.005 时仅允许“未检出预设伤害”的次要表述；任一上界 <−0.005 时为失败边界；其他情况为无结论。FSCAUC 和首次覆盖时间只作描述，不做等效性推断。当前 16 个景观对应的 d=1.2 近似功效计算仅是规划敏感性，不是 pilot 证据，也不替代 cluster-bootstrap 模拟功效审计。

## 预算（budget）、停止与预注册

主析因 12 个 cell ×16 景观×10 seed×3 算法=5760 runs；Q=2 边界 2 个 cell×16×10×3=960 runs；合计 6720 runs、每 run 10,000 NFE。当前只授权生成器、B5R/指标接口和 smoke/precheck；正式 6720-run batch 必须在源、矩阵、seed、统计代码和 run manifest 哈希冻结后另行授权。预注册状态为 LOCAL-ONLY/DRAFT。

## 风险与 Plan B

- 高 Q 下 10,000 NFE 可能只测到稀疏覆盖早期：保持固定预算并报告右删失/低覆盖，不事后加预算。
- 分散布局可能意外产生相邻状态：生成器断言最小间隔，失败即停止。
- B5R 与 B5S 除 targeting 外不一致：做同 schedule、同 injection count、同 selected rows 的契约测试；不通过不得正式运行。
- oracle 泄漏：算法 API 禁止接收 oracle，审计字段必须为 false；发现泄漏则整批作废。
- 16 景观仍可能精度不足：按无结论分支报告；不得因 p 值不理想临时增加景观。
- 解析基准不能代表工程验证：结论限定为受控机制与边界，不推广为机械系统性能结论。
