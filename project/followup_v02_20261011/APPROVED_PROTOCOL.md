# 第二阶段：搜索与保留机制诊断方案 v0.1

日期：2026-10-11。状态：方案已形成，新增优化器尚未实现，性能运行尚未开始，具体运行预算待用户确认。原 420 次正式结果保持冻结，不将本轮视为原预设实验。

## 研究问题及边界

目标不是寻找能显著的组合，而是判断耳切在强截断对照下是否仍有值得继续研究的增量，并分辨种群筛选和引导档案对搜索的影响。

原实现的耳切仅位于环境选择，全部引导档案仍使用一次性 CD；原分层档案保留更多型号，但其主效应未检出显著收益。轨迹诊断发现回落幅度较小，不能据此将整体瓶颈归为末期截断；历史全部已评价候选未保存，因而还无法将搜索收益和保留损失分开。

这一阶段是机制诊断，不足以证明跨问题通用优势或投稿就绪。采用两个已有工况，属于旧结果指导的新探索；新种子不能使工况变成独立验证集。

## 输入、输出与流程

- 输入：原 28 项冻结模型/数据/算子、型号类别变量、连续轨迹变量 `[T,r,u]`、原 9 情景、原 10 项约束及固定归一化；新一轮独立种子。
- 输出：各方法最终可行 HV、工程阈值终点、每代候选产生增益与保留损失、同候选集合反事实截断结果、完整评价历史及耗时。
- 过程：相同初始化 → DE 产生与评价子代 → 分别更新全局引导档案和种群 → 保存全部评价及选择索引 → 运行后统一计算轨迹诊断和反事实截断。
- 流程：新代码准备 → 不调用模型的确定性检查 → 冻结协议与代码 → 已授权范围内运行 → 数据一致性与统计 → 支持/反证/不确定三分支决策。

物理模型、情景、目标、约束及范围完全沿用 `MODEL_CONTRACT.md` 和 `config.json`。保持 F=0.5、CR=0.9、两种变异各 0.5、类别抽样比例 0.1/0.4/0.5。暂不加入参数自适应或额外局部搜索，以免改变待识别机制。

## 3×2 因子矩阵

CD 为一次性拥挤距离；PCD 为每删除一个点后重新计算拥挤距离；EAR 为原覆盖约束耳切。三种种群截断与两种引导档案截断组合：

|编号|种群环境选择|引导档案截断|用途|
|---|---|---|---|
|D0|CD|CD|本轮共同基线|
|D1|PCD|CD|隔离种群 PCD 的作用|
|D2|EAR|CD|原耳切位置的对照|
|D3|CD|PCD|隔离引导档案 PCD 的作用|
|D4|PCD|PCD|强对照|
|D5|EAR|PCD|检验耳切在共同强档案下的增量|

全部使用容量 64 的全局非支配引导档案，不在本轮改变类别配额。移除类别分层是为了控制因子数，不表示原研究证明其有害。六组全部重新采用新种子，旧 420 次不能混入这一比较。

PCD 遵循 Kukkonen–Deb 原文逐点删除并更新邻居的思想；本地参考实现的排序、重复点和并列处理需明示，不冒称与作者程序逐位相同。共同候选按稳定评价 ID 排序；比较距离并列时按 ID 确定，最终返回选中点也按 ID 排序，避免不同算子的返回顺序额外扰动随机数与个体索引映射。相对于旧实现，这一共同顺序约定属于新版本，D0 不冒充旧基线逐位重演。

K=1/2、K=n、重复目标、常量目标、非支配拆分层、可行数不足和不可行排序均需明确处理。EAR 的覆盖上限仍取原一次性 CD 子集的半径，不能在运行后换为更宽的界；单独报告其与 PCD 的真实覆盖差。

## 建议预算与运行顺序

- 6 方法 × 2 周期上限（2.5、3.5 s）× 10 新配对种子（104101–104110）= **120 次**。
- N=64，500 个子代世代；初始化计入，共 **32,064 FE/次，3,847,680 FE/批**。每 FE 包含原 9 情景。禁止缓存省略已计费的模型调用；不加入额外优化或重复种子。
- 单 MATLAB 进程；建议墙钟上限 **1,200 s（20 分钟）**，在每次完整运行保存后检查，上限最多超出最后一个单次运行耗时。这是停止预算，不是预计完成时间。
- 不含新实体试验、FEM、参数调优、更多工况或自动追加重复。运行后从已评价历史计算指标不增加 FE；若需要目标复算，先明确数量并记录为审计计算。
- 方法执行顺序在每个种子中循环平移，种子与方法的算法 RNG 明确重置；工况顺序逐种子交替，减轻热机/顺序对时间比较的影响。
- 120 次全部纳入；超时或失败则保存已完成部分，按未完成报告，不删除失败、不自动增加种子。不能据不完整配对给正式显著性结论。

## 运行后统一诊断

设 P 为上一代可行种群，Y 为可行子代，U=P∪Y，P' 为选择后可行种群，HV 使用原固定归一化和参考点。

- 候选产生增益：G=HV(U)−HV(P)，应不小于零（考虑数值容差）。
- 保留损失：L=HV(U)−HV(P')，应不小于零。
- 核对恒等式 HV(P')−HV(P)=G−L。

L 包含容量限制固有代价，不能将其全部称为算子缺陷。将同一个保存的 U 分别送入 CD/PCD/EAR，保持共同排序、可行优先和同样容量，得到只反映本步删点的反事实差。该离线结果没有反馈后续繁殖，不能冒充优化器长期效果。

令 H 为截至该代全部已评价可行点。报告 HV(H)、HV(P')、最终 H 用共同 PCD 压缩至 64 后的 HV；H 的无界容量使其不是公平的在线求解器。历史并集与种群差包含容量差，需与共同 64 点压缩结果一起解释。PCD 是启发式，不能称其子集为最优压缩上界。

主要质量终点仍是最终种群固定参考点可行 HV；工程终点沿用 0.05/0.1/0.2 µm 下最短周期和可行率。阈值是比较假设，不是已确认的设备精度要求。

## 分析与决策

每个工况分别保留十个配对值、效应量与逐项 95% bootstrap 区间。预设对比 D1−D0、D3−D0、D4−D0、D5−D4、D2−D1；每工况五项精确配对符号秩检验，Holm 校正。另给 D4−D1−D3+D0 的交互差描述，不另行挑选显著性。bootstrap 固定种子 20261011，10,000 次；不把逐项区间称为多重比较同时区间。

十次重复是有限预算的诊断样本，没有事先功效保证；不显著不等效，不对两工况作总体泛化检验。运行前冻结代码与本协议哈希，修订另存 amendment。

- 若 D5 对 D4 的配对结果和工程终点支持实际收益，且同集合诊断能解释收益，继续核查耳切具体机制与前作差异；不能跳过独立确认直接宣称创新。
- 若 PCD 已吸收耳切的表现，取消“耳切优越性”作为文章核心，改为可解释的算法适用性或工程联合设计研究；原负结果保留。
- 若所有方法搜索覆盖均不足，则转向问题结构、变量耦合与探索机制，另立假设和预算；不在本轮即时调参追求显著。
