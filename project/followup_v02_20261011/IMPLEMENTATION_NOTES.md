# 运行前实现细节（2026-10-11）

用户已明确批准原建议的 120 次/3,847,680 FE/单进程 1,200 s；APPROVED_PROTOCOL.md 保留原提议文本，授权状态以 provenance/authorization.json 及原生 ARIS 记录为准。

PCD 在当前非支配拆分层逐点删除最小 CD，更新两目标邻居。精确距离并列时删去最大稳定 ID，从而优先保留较早 ID；K=1 采用原 CD 选择。若删边界（退化/重复目标可导致多个无穷 CD），重建距离及范围。输入与输出均按稳定评价 ID 排序；模型和原算子文件不修改。邻居实现用独立全重算版本及保存前沿核对，不把单次时间当算法复杂度实测。

原 EAR 原样复用（包括已有 1e-12 面积/覆盖并列容差和回退），其候选按稳定 ID 排列。输入是非支配拆分层；每次保存该层 rank、大小、K、覆盖半径、上限及回退。全局档案先按 X 去重，再按目标非支配过滤，目标完全相同时按稳定输入顺序选代表；与旧机制的区别明示为返回顺序规范化和指定截断函数。

候选 ID 对应历史矩阵行号。初始 ID 1–64，第 g 代子代 ID 为 64g+1 至 64(g+1)。population_ids 和 archive_ids 的行号 g+1 表示第 g 代状态，档案未用槽以 0 填充。这些确定规则完整给出每代父代、子代及档案更新前后，不另存重复 ID 表。

history_X、history_F、history_CV、history_G 记录每次实际模型调用的输入、输出和 10 项原始约束；没有缓存免计费或重复评估。历史矩阵是存储容器，繁殖只读取当前种群/档案对应行，所有离线反事实在运行后计算，不反馈搜索也不消耗算法 RNG。

compute_seconds 覆盖初始化至最后日志行内存写入，component_seconds 分列初始化、目标评价、变异、选择、档案、内存诊断记录，少量调用和数组初始化开销包含在总时间中。execution.log 的 save_inclusive 覆盖该次运行、MAT 保存与两个 CSV 写入；批次 wall 包括全部运行和文件输出。六组采用相同记录方式，不能与旧实现未包含初始化的计时直接比快慢。

预检不调用 bs_evaluate，不进行未计账的短优化运行。所有性能运行只有批准的 120 次；批次超时在运行间检查并停止，不自动续跑或换种子。

首次静态检查提示 PCD 嵌套函数循环变量共享。性能运行前将临时变量改为各作用域不同名称，消除隐式共享风险；原预检及初始清单保留为 before_scope_cleanup 文件，重新通过相同几何检查后冻结。该清理没有查看新性能结果，也没有消耗模型 FE。
