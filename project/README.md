# 滚珠丝杠动态联合设计研究（独立扩展）

本目录保留原 v2.4 解析枚举研究，以新的动态问题检验耳切 MODE 的适用性。研究日期：2026-09-21。用户已明确：使用中科院分区；先完成可复核数值研究，结论限于模型预测。非 OA 目标为 3/4 区，OA 只接受 2/3 区；录用与分区不作保证。

当前定位：420 次正式比较与审计已完成，新增机制尚未显著优于基础 MODE。结果见 `analysis_formal/RESULTS_zh.md`，英文修订稿见 `manuscript/manuscript_en_formal_v02.md`。研究仍不能直接投稿，详见 `STATUS.md`。

## 输入、输出与计算逻辑

- 输入：原项目 19 个 THK BTK-V 型号的不可拆分目录记录；0.4 m 行程、0.65 m 丝杠长度及其余显式假设；运动时间、加速段比例、加加速段比例。
- 输出：单程时间、周期稳态运动结束后的最坏情景轴向残余振动包络、保守约束上界，以及原始候选和诊断。
- 过程：构造七段 S 曲线 → 串联轴向刚度 → 线性基座激励模型 → 分段解析传播及周期初态求解 → 情景汇总和约束检查 → 独立 ODE 核验 → 问题结构检查 → 同预算算法比较。
- 流程：目录完整性检查 → 参数证据分类 → 模型 verification → 结构筛查 → 固定实验协议 → 运行/日志 → 统计与机制分析 → 工程复核 → 论文写作。
