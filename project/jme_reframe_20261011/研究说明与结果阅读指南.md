# 研究说明与结果阅读指南

日期：2026-10-11。对应题名：《基于梯度度量匹配的重载机器人速度历史补偿模型优化》。本说明用于解释研究对象、计算证据和复现入口；不作为论文正文的一部分。

## 1. 题目中的“优化”具体是什么

论文围绕重载机器人动力学补偿模型的构建展开。比较“当前速度输入”和“速度历史输入”时，可以把当前速度重复K次形成等维对照。重复列携带相同观测，网络可以将它们折叠为有效参数之和，但原参数空间的正则项、梯度范数和Adam步长会随表示改变。若不处理这种变化，模型间的训练差异可能被误解为历史信息作用。

本文把优化对象落实为这个重复支路：折叠冗余参数，同时匹配正则化、参数块学习率和裁剪度量，保留规定条件下的训练行为。真实不同时刻的速度通常不相等，不能采用该折叠；历史模型Hδ仍有66048个参数。因此，“减少5.51%”专指重复当前速度对照的资源减少，不能写成历史信号压缩、所有模型压缩或预测精度提高5.51%。

这也限定了贡献强度：函数保持和Adam尺度等价已有直接文献基础，本文将这些条件与复制输入、跳跃支路及全局梯度裁剪结合，给出可核验的推导和机器人数据上的条件检验。没有提出一种通用新优化器。

## 3. 理论怎样成立

设重复列参数为w_l，有效参数w=Σw_l。平方范数分解为：

Σ‖w_l‖²=‖w‖²/K+Σ‖w_l−w/K‖²。

同值输入的数据函数只依赖w。固定w且正则系数λ>0时，第二项在所有列相等时最小，由此得到紧凑表示的λ/(2K)‖w‖²；其余参数保持原λ/2正则。这里证明的是消除零和冗余方向后的目标对应。任意不对称列虽然可在当前时刻折叠函数，却不能仅凭有效权重恢复其正则值与Adam状态。

有效梯度g_w在宽表示中复制K份，所以对应范数是G²=K‖g_w‖²+‖g_ϑ‖²。若紧凑网络直接使用普通范数G₀，裁剪判断就可能改变。令ρ为输入/跳跃块占总梯度能量的比例，可得G/G₀=√[1+(K−1)ρ]，裁剪倍率比介于1与√K之间。图2的散点来自实际逐步记录，曲线是解析关系；曲线覆盖的全部ρ范围不等于实验都访问过。

在重复列对称、相应Adam矩状态一致、同一批次、数据梯度先裁剪再加耦合L2等条件下，紧凑输入/跳跃块使用Kη与λ/K，配合上述范数，能在精确算术下逐步对应宽模型的有效更新。这一条件不自动适用于AdamW、任意裁剪顺序或任意初始矩状态，也不证明损失逐步下降、全局收敛或机械误差减小。

参数梯度度量与机器人惯性度量是两件事。前者来自参数表示；后者在加速度拟合中由逆惯性及输出尺度形成。论文式10将二者分开，不能把这里的K加权称为机械自然梯度。

## 4. 实际执行了哪些计算

|证据|条件与数量|能回答的问题|
|---|---|---|
|既有完整训练|D_s、V_m、Cδ、Hδ；3个种子；每个模型10000步|长程有限精度下的路径对应与固定选模规则下的预测表现|
|本次机制条件计算|K=1/3/7，γ=1/100/关闭，3个初始化；27组，每组5模型、200步|分别取消范数、步长或L2匹配后，路径是否改变；负对照是否按理论退化|
|实际状态统计|135个最终模型及其Adam状态，另核对既有6个D_s/V_m状态|参数量和权重加双矩字节数是否确实减少|
|既有机械预测评价|同机同日33轨迹，306个滚动窗口；另有原评价记录|历史输入的点态和短时滚动用途，不能替代跨机器人验证|

新增计算实际执行27×5×200=27000次参数更新，保存5400条分组逐步记录。固定1024个训练样本在第1步及每10步检查一次，每个模型每组21次检查；4个紧凑模型共有2268项比较，其中完整匹配M为567项。它们不是2268次独立实机实验，也不是验证或测试样本。全部设置在本次运行前写入协议，但整体研究已经看过既有评价，故属于事后机制检验。

三类失配为：N只用普通范数，L只取消输入/跳跃块的K倍学习率，R只取消相应λ/K正则。K=1时所有规则一致；关闭裁剪时N与M一致。这两个负对照都实际通过，支持“只有机制被触发时，相应规则改变才会起作用”的解释。

## 5. 怎样读结果

完整匹配M在567项短程检查中的最大无量纲输出差为3.9968×10⁻¹⁵，小于预定10⁻⁹容限。这是相同训练样本上两个实现的网络输出差，不是加速度误差，也不是位置精度。长程完整训练仍有7/300个检查点超限，说明短程成功不能推出任意长度的有限精度保持。

K=7时，参数由66048降至62412，减少3636个，比例5.51%。float64权重加Adam一、二阶矩载荷由1585152 B降至1497888 B，节省87264 B，即85.22 KiB。该统计不含梯度、激活、步号、序列化和进程开销；没有报告运行加速，不能改写成“训练内存下降5.51%”。

既有Hδ/Cδ比较中，33轨迹平均加速度NMSE变化为−1.34%，0.6 s位置NRMSE变化为−5.16%。三个初始化中一个恶化，且Hδ整体位置误差优于恒速外推的轨迹为0/33。换向子集的相对表现另行报告，不能借局部优势抹去整体负结果。D_s/V_m点态误差也低于Hδ，因此数据不支持“历史模型优于全部当前速度模型”。

|量|单位或口径|不能混用的量|
|---|---|---|
|网络输出差|未还原力矩尺度的无量纲最大绝对差|真实力矩、加速度或位置误差|
|加速度NMSE|按训练加速度标准差归一化的均方误差|原量纲rad·s⁻²的RMSE|
|位置NRMSE|按训练位置标准差归一化的均方根误差|实际末端毫米误差或工艺容差|
|张量存储|参数权重及Adam两个矩的字节数|进程峰值内存或运行时间|

## 6. 数据与物理解释范围

沿用Retzler等论文的公开机器人研究材料和roblue固定提交，官方原始数据DOI为10.26204/data/5。保留原始文件、来源许可、训练/验证/评价划分和固定物理基底。本次未增加机器人、载荷或实机采集。

速度和加速度由整段位置经FFT平滑及频域微分得到，包含未来样本，不是独立传感器真值；滚动预测使用已知未来记录力矩。固定物理基底存在较大误差，18个摩擦参数条件重估不能消除整体失配。由此不能认定模型辨识了真实摩擦状态，也不能声称完成在线闭环控制或跨工况验证。

27条参考文献均与第五轮书目逐字一致，核验链保存在“参考文献继承核验.md”。直接先例Ma等本次重新阅读官方v2，明确归属已有训练动态等价规律；没有为增加数量加入无关条目。
