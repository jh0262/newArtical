# Paper code and reproducibility resources

This repository collects research code and supporting resources in separate branches named after each paper or research project. The main branch serves as the index.

The resources are being organized from the author’s research workspace. Each paper branch records its implementation, dependencies, reproduction entry points, resource provenance, and actual research status. Existing numerical records are preserved.

Initial upload: MO-PACPO for multiobjective dimensional design of a 2PPaPaR parallel mechanism. The branch index will be updated after remote verification.

Prepared on 27 October 2026.
