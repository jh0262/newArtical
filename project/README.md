# EarClip MODE multi-mechanism study

Status: implementation and verification; no performance result yet. This is a new candidate study, independent of earlier projects named EC-MODE or CM-MODE. The user explicitly authorized MATLAB implementation, ablation, classical comparisons and at least 500 generations on 2026-09-05. No claim of external novelty, algorithm superiority, or engineering/physical validation is implied.

## Input / output / process / flow logic

- Input: eight analytic, continuous, unconstrained bi-objective benchmarks; bounds and objective definitions from a locally archived PlatEMO source snapshot; explicit seeds and configuration.
- Output: MATLAB source, tests, all successful and failed run records, initial/final decisions and objectives, every-generation population objectives and HV, IGD+ at common checkpoints, adaptation traces, CSV tables, plots and Chinese analysis.
- Process: freeze design -> verify formulas/selection/operators -> independent same-seed reproduction -> execute every matrix row -> independently recompute metrics -> factorial ablation and baseline comparison.
- Flow: initialize 100 solutions -> generate/evaluate exactly 100 offspring -> update data-driven parameter memories -> non-dominated environmental selection -> repeat 500 times -> save raw evidence. Classical algorithms retain their source-defined variation and selection.

## Registered experimental design v1

- N=100, M=2. Exactly 500 reproduction generations, plus initialization: 50,100 evaluations per run. No early stopping or population reduction.
- Problems: ZDT1/D30, ZDT2/D30, ZDT3/D30, ZDT4/D10, ZDT6/D10, DTLZ2/D11, DTLZ4/D11, DTLZ7/D21. All minimize both objectives. These are dimensionless analytic benchmarks, not mechanical models.
- 20 independent algorithm seeds per problem and variant. Same initial decision matrix within each problem/seed block, generated by a separate random stream. Primary total: 8*20*13=2080 runs.
- Eight factorial variants G000..G111: A=ear/coverage truncation; B=geometric guide weighting; C=feedback allocation between rand/1 and current-to-guide/1. All eight use the same success-history-inspired F/CR adaptation.
- Additional algorithms: fixed-parameter MODE (A=B=C=0, F=0.5, CR=0.9); official PlatEMO NSGAII, SPEA2, MOEAD (Tchebycheff option type=2, explicitly selected to avoid the PBI angular singularity); G111_SHUFFLE preserves guide weights but randomly permutes their association with decisions.
- F and CR adaptation is shared support, not a fourth factorial factor or an exact reproduction of single-objective SHADE. Archive success credit replaces SHADE's scalar-fitness credit; this difference is explicit.
- Classical default operator parameters remain source-defined. No result-driven tuning of classical or candidate variants. Hyperparameters, including memory size, probability floor and learning rate, will be recorded. Adaptive does not mean parameter-free.

## Mechanisms

A: on the overflow non-dominated front only, use its fixed min/max normalization. First compute ordinary crowding-distance truncation to K solutions and its maximum original-point-to-retained-point Euclidean covering radius. Use that radius as a data-adaptive admissibility bound. Starting from all points sorted by f1, delete the smallest local triangle area among deletions whose accumulated covering radius does not exceed that bound. Protect extremes when K>=2, update neighboring ears after every deletion, and retain all original points for coverage checks. If greedy deletion gets stuck, return the precomputed crowding subset and record fallback. No Pareto convergence or optimal subset guarantee is claimed.

B: use the preceding generation's **pre-truncation non-dominated candidate set** as the guide pool, so compression-created holes are not directly treated as undiscovered gaps. Normalize using this observed pool only. Weight guides by capped neighboring distances and normalized local bend; cap long distances with a median/MAD rule to limit persistent gaps. B=0 uses uniform guide probabilities over that identical pool. Objective-space geometry selects indices; all DE arithmetic is in decision space. It does not guarantee feasible objective-space interpolation or identify true disconnected components.

C: allocate offspring between ordinary DE/rand/1 and DE/current-to-guide/1 using smoothed, per-attempt marginal HV credit relative to a fixed, observed pre-generation guide pool. Each arm retains probability >=0.1. C=0 fixes the mixture at 0.5. The adaptation reference is based on observed objectives, never the analytical true PF. Credits are computed against the same frozen anchor for a whole batch (not population survival); they can overlap and are explicitly individual potential gains, not additive batch attribution. The one-generation guide window avoids direct delete/reinsert credit but is not a complete discovery history.

F/CR: six memory cells, initial means 0.5/0.9; positive Cauchy scale 0.1 for F (cap at 1), clipped normal standard deviation 0.1 for CR; gain-weighted Lehmer mean for successful F, gain-weighted arithmetic mean for CR. If no positive credits, do not update memories. C uses EWMA learning rate 0.1 and probability floor 0.1. These are registered implementation constants, not optimized values.

## Outcomes and analysis rules

Primary outcome: final IGD+ (smaller is better), computed against fixed reference-front samples and fixed objective-wise reference bounds; optimization code cannot access these reference samples. Secondary: normalized exact 2-D HV at fixed reference (1.1,1.1), convergence, wall/algorithm time, covering radius, duplicates, fallback and parameter/arm traces. Report HV outside-reference fraction; points outside the reference contribute zero, not an undocumented clipped contribution. Store raw fronts so all results can be recomputed.

Analysis unit for across-problem comparisons is the problem, using seed medians. Seeds quantify run-to-run randomness and are not 160 independent landscapes. Report all 8 factorial cells, marginal A/B/C effects and pair/triple interactions on the predeclared raw IGD+ scale; show problem-specific effects. Classical comparison: Friedman ranks across the 8 problem medians and paired Wilcoxon comparisons of G111 to the other algorithms with Holm correction. With only eight problems, statistical generalization is limited. Also report paired seed-level effect distributions per problem descriptively. No exclusion of bad but valid runs. No selecting only favorable functions or seeds.

## Hypotheses / failure tree / amendment policy

- H-A: coverage-bounded deletion changes survivor geometry without exceeding the ordinary-CD discrete coverage radius on the same candidate set. Guardrail: exact radius inequality, extreme preservation and non-dominance priority. A fallback is valid but must be counted; all-fallback behavior undermines mechanism contribution.
- H-B: correct geometric association helps beyond uniform and shuffled guide selection. No effect versus shuffled control weakens the information-transfer explanation.
- H-C: online allocation helps beyond a fixed mixture with identical operators and F/CR adaptation. Failure is a valid negative result.
- H-ABC: combination yields positive interaction on the declared metric scale, rather than only beating fixed MODE. Inspect all factorial cells; no guaranteed synergy.
- Failure branches: numerical/API/missing-output -> preserve failed record, diagnose and correct; performance weakness/non-significance -> report unchanged, not a bug. Underpowered/inconsistent evidence -> inconclusive.
- Preflight fixtures and short smoke runs are verification only, excluded from formal statistics. Formal performance runs begin only after tests, reproduction, source/config hashes and manifests exist. Any subsequent change to algorithm, budget, metric, problem set or seeds receives an explicit version/amendment and separate outputs; no silent overwrites.
