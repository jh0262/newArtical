# 补充材料S7 方向与触发条件对照及MOCPO文献复现

本材料对应2026-10-25创新性对照单栏修订稿。S1—S6沿用既有《MO_PACPO_实验与数值验证补充材料》。本轮保持2PPaPaR刚体3T1R、四尺寸三目标、既有误差假设和原Full算法。

## S7.1 设计及来源

DL为原Full，DR改变脉冲方向，SL改变触发条件，SR同时改变二者。30次配对重复、每次25 100次评价。新增三组共810次搜索；DL的270次既有运行经完整评价带重放后复用，重放不增加独立样本数。随机方向逐个匹配各自当前状态内投影样本的范数，边界截断后范数可改变；方向变化造成的后续路径差异属于总效应。

四组保留成功率清零停滞计数规则。单条件取消低方差子空间非空这一门；低方差集合为空时，以最小特征值特征向量定义对应投影。完整参数和独立辅助随机流规则见运行前冻结的PROTOCOL.md及P4Pulse.m。

MOCPO依据Adalja等（2025），Scientific Reports 15:14380，DOI 10.1038/s41598-025-99207-1的出版社HTML、PDF及Algorithm 1实现。原文实验使用种群40、1000轮；本研究按统一初始种群100和评价预算25 100进行比较。原文没有公开作者源码，也没有定义多目标信息反馈中的标量适应度，本轮保存两种预设解释：F为固定归一化目标均值，R为中间解和随机抽取父代的联合非支配等级。结果对应这两种固定规模论文复现配置。



| 项目 | 冻结实现 | 依据/性质 |
|---|---|---|
| 多目标IFM适应度 | F：固定问题归一化目标的均值，截下限1e-12；R：父代与中间解合并后的非支配等级 | 原式使用标量f但没有定义向量目标到标量的映射；两种预设解释均报告 |
| 四分支概率 | 探索/开发各1/2，内部分支各1/2 | 原文描述随机切换，未给数值；固定中性概率 |
| α、β、δ | 各0.5 | 式(6)、(7)、(9)未给参数值；相同半步尺度 |
| γ与Brownian | γ=0.01，标准独立高斯向量；归一化决策域[0,1]^D | 式(8)的小幅Brownian扰动的明确数值实现 |
| 全局引导G | 从可行性优先的第一非支配层均匀选择 | 多目标最优位置的复现解释 |
| 邻域引导B | 当前父代归一化目标最近10个个体中先按约束/等级、再按拥挤距离选择 | 原文未定义邻域；固定规则 |
| 种群与周期缩群 | Algorithm 1固定N=100；式(5)取Nmin=N，保留固定规模比较 | 与主实验同种群的固定规模配置 |
| 边界与约束 | 截断到[0,1]；可行性优先，等CV按非支配/拥挤距离 | 与机构模型统一的必要接口 |
| IFM后处理 | 不额外加入MO-PACPO的差分、主轴、脉冲或多项式变异 | 严格按文献的混合与环境选择 |
| 最终输出 | 最终种群的非支配可行集，最多100 | Algorithm 1返回下一代种群；不另加跨代外部精英档案 |

上述参数为本研究的预设复现设置；作者程序的对应参数未公开。性能比较针对两种固定规模论文实现。



### 公式与源码对应

| 文献位置 | 实现位置 | 数值处理 |
| --- | --- | --- |
| 式(6)—(9) | MOCPO2025.branch | 四分支分别为朝G移动、朝随机P移动、高斯Brownian、朝邻域B移动；归一化决策域截断 |
| 式(11)、Algorithm 1式(12) | MOCPO2025.feedback | w=s_k/(s_u+s_k)，q=w u+(1−w)x_k；F版分数下限10⁻¹² |
| Algorithm 1式(13)—(15) | P4Core.select，由MOCPO2025.solve调用 | 父代与最终子代合并，约束支配分层，末层拥挤距离截断 |
| Algorithm 1输出 | MOCPO2025.front | 最终种群非支配集，目标去重；无跨代外部档案 |
| 每轮两次评价 | MOCPO2025.solve/evaluationStage | 中间解和IFM后解各100次；初始100+125×200=25 100 |


全局引导从约束优先的第一非支配层均匀抽取；邻域为固定归一化目标空间最近10个父代（含自身），按等级、当前整个父代种群的拥挤距离、索引选择。R版联合排序包含中间解和带放回抽取的反馈父代。正文式(10)分子分母相同，环境选择采用Algorithm 1式(15)的相邻差公式。

## S7.2 数值与预算核验

9项MATLAB测试通过。全部1350次新增搜索完成，共33 885 000次优化评价；每配置30次。同问题各组前100个初始决策、目标、约束及记录完全一致。中间评价计入预算，最终档案均能追溯至原始评价记录。机构最终档案另用共同262 144和1 048 576点积分复核，该重评不参与搜索。

独立Python流程重读MAT双精度原始值，复核均值、标准差、符号秩检验、Holm校正、20 000次bootstrap区间及540对完整轨迹；另以不同切片方向的递归实现核对162个预先指定档案的HV。验证记录见audit/independent_verification.json。

## S7.6 零差值下的检验敏感性

部分触发对照的30对结果中含较多零差值，因此在原预设近似检验之外补做精确条件符号秩检验。该项为观察零差结构后增加的统计核验，主表仍采用预设近似检验。精确分布用加倍平均秩的整数动态规划计算，保留绝对差并列秩，并按原比较族重新进行Holm校正。

全部196项比较中，近似与精确校正检验的0.05显著性判定差异共0项。完整数值见data/signedrank_exact_sensitivity.csv。

两种检验的显著性判定一致。
