# 模型契约 v0.2

## 研究问题与贡献假设

旧“质量—峰值变形”问题已可按 19 个型号解析枚举，不适合作为新 MODE 必要性的证据。新问题研究周期往复运动中单程时间与轴向残余振动的情景折中。联合设计、S 曲线和输入整形本身已有前作；拟检验的核心是覆盖约束耳切选择在混合离散、受约束的双目标前沿上的作用。未预先承诺其优于现有算法。

## 运动轨迹

令 h=rT，t_j=uh，t_a=h−2t_j，t_v=T−2h。七段时长为 [t_j,t_a,t_j,t_v,t_j,t_a,t_j]，加加速度为 [J,0,−J,0,−J,0,J]。

\[
J=\frac{L}{t_j(h-t_j)(T-h)},\quad v_{max}=\frac{L}{T-h},\quad a_{max}=\frac{L}{(h-t_j)(T-h)}.
\]

分段积分得 x(T)=L、v(T)=a(T)=0；J 单位 m/s³。下行取轨迹符号相反。不称为 jerk-continuous 曲线：该轨迹 jerk 有跳变，速度和加速度连续。

## 降阶动力学

轴向刚度 k=(1/k_n+1/k_s+1/k_b)⁻¹，k_s=EA/L_s。全部换算为 N/m。每情景使用 k_ω=κk、m=外载荷+螺母质量，ω_n=√(k_ω/m)，ω_d=ω_n√(1−ζ²)。

以受重力静变形位置为基准，定义 q 为实际位移减去理想指令位移：
\[
\ddot q+2\zeta\omega_n\dot q+\omega_n^2q=-a_{cmd}(t).
\]

这是理想基座跟踪、单轴向模态、常系数小振动模型。丝杠轴向分布质量、扭转、联轴器、支架和机架模态、接触刚度随载荷变化、摩擦、间隙切换及控制闭环均不在模型中。不得把本模型精度外推到实体机构。

段内 a=a₀+jt 的特解为 q_p=−a/ω_n²+2ζj/ω_n³，v_p=−j/ω_n²。齐次部分用解析指数衰减正弦传播。利用线性系统的上下行反对称性，令 Φ 为时间 T+d 的齐次转移矩阵、b_d 为零初态上行后再停留 d 的响应，周期初态满足 (I+Φ)s₀=−b_d。此条件避免把每次运动的初态错误重置为零。周期稳定性来自 ζ>0，不代表真实伺服稳定性。

运动末端残余包络：
\[
R=\sqrt{q(T)^2+\left[\frac{\dot q(T)+\zeta\omega_n q(T)}{\omega_d}\right]^2}.
\]

停留 τ 时 |q(T+τ)|≤R exp(−ζω_nτ)。优化目标 f=(T,max_s R_s)，以 s、μm 输出。最大值只覆盖列出的有限情景，不宣称连续不确定域保证。

## 约束与保守界

1. 2(T+d)≤2.5 s；目录 RPM、DN 和原固定—支承临界转速筛选。
2. 每段分解为 affine 特解与衰减正弦齐次解；用齐次幅值构造全段轴向载荷与变形上界。该上界可能保守，但不依赖稀疏时间采样。
3. 接触载荷在整个上下行周期均为正：mg−F_dynamic_bound>0。THK BTK-V 为无预压型号，该条件用于模型内维持单侧受载；不是消除实际间隙的证明。
4. 静载安全系数≥1.5、屈曲安全系数≥2、保守轴向变形≤30 μm。
5. 峰值转矩筛选 τ≤F_upper p/(2πη)+J_s(2π/p)a_max≤5 N·m。J_s 使用 THK A15-243 的单位长度转动惯量（kg·m²/mm）乘 650 mm，19 行已核对 PDF 表格。v0.1 试运行曾采用旧模型的根径实心轴近似，保留在 provenance 与旧 pilot/verification 中，不能与 v0.2 正式结果混用。没有纳入电机转子惯量及摩擦，不代表整机最大驱动转矩。
6. 寿命筛选使用 F_upper×载荷系数 1.2 和周期平均转速。它是目录额定寿命关系的保守代入；没有实测载荷谱，不能预测真实使用寿命。

新研究暂不复用旧 RMS 转矩结果；必须在新轨迹下重新积分后才能使用 RMS 指标。所有约束采用无量纲比值减 1，正值表示违反。约束容差 1e−10 为数值判定，不是机械余量。

## 必须完成的校核

- 七段轨迹终点与连续性；每项量纲。
- 解析响应对独立高精度 ODE；周期初态回代。
- 停留衰减包络；全周期密集积分载荷/变形不得超越解析界。
- 名义与不确定情景；阻尼、刚度范围和周期上限敏感性。
- 固定型号的时间响应非单调性与参考搜索；非单调性本身不证明必须使用 MODE。
- 算法比较必须含按型号分解的数值搜索；若其已足够好，缩小 MODE 的研究结论。

## 模型形式敏感性（补充，不是物理验证）

另建两个轴向自由度：丝杠端部 z₁ 与螺母/负载 z₂，均相对理想基座。采用假设的线性轴向形状，丝杠等效移动质量 m_s=ρ_l L_s/3；M=diag(m_s,m)，k_b*=(1/k_s+1/k_b)⁻¹，K=[[k_b*+k_n,−k_n],[−k_n,k_n]]。求解广义特征值问题 Kφ=ω²Mφ，质量归一化后，各模态施加相同假设阻尼比，参与因子 Γ=φᵀM[1,1]ᵀ。

各模态沿相同七段轨迹解析传播并满足反周期初态；负载残余位移为 Σφ₂j Γ_j q_j。输出两个不同量：模态包络和上界 Σ|φ₂j Γ_j|R_j，以及停留阶段高密度采样的最大绝对位移。后者是采样结果，不声称精确峰值；前者是保守界。本补充仍没有扭转/伺服/机架模型，只检查增加轴向惯性自由度对所选设计的影响。
