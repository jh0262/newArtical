# 正式结果绘图计划

编写时正式队列仍在运行，尚未读取完整性能汇总。这里固定展示 F01/F03/F05/F08/F09/F23 六题的三算法收敛；工程 WB/CB/PV 全部展示。该选择属于结果分析前的图表规划，不改变冻结的优化实验协议、主检验、预算或种子。

调用（完整正式分析生成后）：

```matlab
manifest = pade_plot_results(fullfile(pkg,'analysis'), fullfile(pkg,'figures'));
```

默认生成中英文两套、共14张图（包含实现流程图），每张包含可编辑 FIG、300 dpi PNG 和矢量 PDF。需要仅英文时增加 `Languages="en"`。函数要求5640次正式运行、全部26题、每配置种子1001—1030、complete状态和精确终态FE预算，拒绝统计人工夹具和部分结果。

六类图分别为：相同 FE 基准收敛；工程收敛与可行率；预设 family 的 Holm 胜/未检出差异/负与主要对照效应；核心机制消融及 PV 六组 J 对照；实际机制活动及 FE 占用；所有工程配置的最终可行目标分布与可行率。

收敛依据每次运行的真实无损改进日志，在共同 FE 网格前向保持；不做线性插值。中位数/四分位距显示实际种子间分布，不当作置信区间；零目标不替换为正数。工程目标仅在可行子集内汇总，同时画出全部运行的可行率。活动指标和性能结果分别展示。

`source_data` 逐图保留可复核 CSV；每图有中英文完整图注及统一 FIGURE_MANIFEST。未运行绘图时不会产出任何模拟性能图。

`pade_plot_flow(figureDir,Language="en")` 可独立生成 14.8×15 cm 的论文图1；它仅表现冻结代码的控制流程，包含实际 FE/B 门、逐候选预算检查、Q/J/Q 和末代部分执行，不需要也不含性能数据。主绘图函数也会自动调用它。正式分析目录名不限，`pade_plot_results(fullfile(pkg,'results'),fullfile(pkg,'figures'))` 同样有效。
