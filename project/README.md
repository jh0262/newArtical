# ALG1-Replan

ALG1-Replan 是在旧 `ALG1_TCAC_SHADE` 项目按冻结规则返回
`NO_GATE / FAILURE_STOP_RG_ROUTE` 后建立的独立研究分支。它不修改、覆盖或
重新解释旧分支的 360 个不可变运行包与阴性结论。

本分支的目标是形成一个经过文献撞车审查、机制可证伪、完整实现并在等 FFE
预算下完成基准、消融、统计、复杂度和稳健性验证的约束优化算法研究包。

当前证据状态：I3/CVGR-SHADE 研究方案 v0.1 已冻结，但客观新颖性仍为 `UNKNOWN`，且尚无本分支性能结果。生产实现、优化器执行和正式 FFE 均未获授权。

## 证据边界

- 旧分支证据只作为问题形成和失败约束，不作为本分支算法性能证据。
- 任何候选算法必须使用评价前可得信息；不得使用当前子代的目标、约束、接受
  结果或成功参数进行当前动作选择。
- 软件测试证明实现与契约，不证明算法有效。
- 只有完整、冻结且独立执行的实验矩阵才能支撑性能或优越性主张。

`预注册 -> TDD覆盖修订与冻结 -> 分层完整实现 -> 独立基准实验 -> 统计与消融 -> 论文证据审计`
