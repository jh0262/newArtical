# 割耳机制与多目标优化：新研究项目

建立日期：2026-09-06。研究状态：选题与前作初筛。用户目标：从选题重新开始，研究一篇采用新方法的纯多目标优化算法论文，并沉淀可复用研究规范。

## 当前研究约定

- 本项目成为当前论文研究主线，按每周 30–40 小时、每双周 70 小时规划。
- 暂按“设计一个新的多目标优化方法，以割耳相关机制为核心”理解“新的算法”。如果用户指的是改进一种已有较新算法，再根据其回答调整；不凭发表年份指定基础算法。
- 首篇范围建议为连续、无约束、双目标最小化；双目标属于多目标优化。该范围是当前建议，不是假定用户已经确认的硬约束。
- 研究对象是优化算法与解集选择，不以 ANSYS、机械案例或实物试验作为必需交付。
- 旧 EarClip_MODE_Study 是已完成的历史研究。保留其代码、数据和结论，只作失败案例及已知信息来源，不复制为新算法，不重新包装旧结果。
- 本轮完成选题初筛与研究规范 v0.1；尚未确定最终算法、通过外部新颖性审查、实现优化器或启动性能实验。新颖性未知不是研究流程失败，而是当前应解决的研究任务。

## 建议的论文问题

**在有限种群容量下，能否将割耳式局部几何操作改造成有明确损失评价的环境选择，使其改善解集质量，并在相同评价与选择计算预算下改善进化搜索？**

工作题名：**面向双目标进化优化的冲突感知批量割耳式环境选择**。

题名用于组织选题，尚不是最终投稿标题，也不预设方法优于现有算法。优先查证的候选是“显式处理相邻删除互扰的批量选择”；它仍有与并行割耳、已有双目标子集选择等价的风险，不能现在命名为已成立的新算法。“可回退的局部删点与交换”在本次检索中发现直接相关前作，已降为高碰撞风险备选。
