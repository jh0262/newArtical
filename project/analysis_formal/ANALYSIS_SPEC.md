# 正式结果分析实现约定

本文件在批次运行过程中、汇总比较前写入；不改变已冻结的算法、模型、种子、目标缩放、预算或主要比较。

- 420 个 MAT 是主记录，CSV 仅交叉核对。校验矩阵完整、每次 32,064 FE、64 个最终设计、501 行轨迹、相同冻结清单、目录编号和连续边界。
- 使用独立 Python 矩形并集积分复算最终 HV；全部可行种群返回 MATLAB 当前模型复算 F/CV。后者是结果审计，不是额外优化预算。
- 候选 MODE-EAR-S 对其余六方法，在每个工况内使用配对 Wilcoxon 符号秩检验；差值先按 1e-12 舍入以去除表示误差。删除零差，绝对值相同取平均秩，动态规划精确枚举秩和的符号分配概率；这仍要求差值关于零对称。每工况六项 Holm 校正。
- 报告原始均值/中位数/样本标准差，候选减对照的差值均值、中位数、胜/负/平、配对秩二列效应量。差值均值的 95% percentile bootstrap 区间使用 10,000 次重采样，固定分析种子 20260921；区间是逐项区间，不是多重比较同时区间。
- 2×2 消融按种子计算 A=[(A1B0−A0B0)+(A1B1−A0B1)]/2，B=[(A0B1−A0B0)+(A1B1−A1B0)]/2，I=A1B1−A1B0−A0B1+A0B0。每工况三项校正；交互为正不自动意味着组合优于基线。
- 工程终点：在每次最终可行种群内，查找残余包络≤0.05/0.1/0.2 μm 的最短周期 2(T+0.25)。无点满足记缺失，报告满足次数和仅满足运行的条件中位数，不能填零或忽略失败次数。
- QMC 的可行率轨迹为累计样本可行率、其第 5 列为未压缩前沿大小，与 MODE 种群指标含义不同；只比较重新计算的最终可行率/唯一点数及共同 HV 指标，不混画这些不同语义的轨迹。
- 程序报告的 search_seconds 不含文件保存，MODE 还不含初始 64 个点的模型评价。时间只作本机参考；批次总墙钟时间以执行日志为准。
- 统计脚本是本次实现、同一执行者自检；不称独立外审。跨工况不作统计汇总或普遍优越性推断。
