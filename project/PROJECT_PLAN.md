## 1. 研究问题与边界

候选贡献的受控表述是：利用在线约束违反图的稳定群落与交叉群落违反排序，为不可行目标选择有向差分供体，并在适用条件不满足时逐步回退到 FR-SHADE。本计划检验它是否能够：

1. 恢复预先已知的约束块结构；
2. 增加指向主导违反块下降方向的候选差分比例；
3. 在相同 FFE、种群规模、初始化、停止条件与约束比较规则下，改善问题级约束优先终值分布；
4. 在激活条件不满足时保持与父算法逐步、逐随机流、逐 FFE 的回退一致性。

研究对象不是“任意约束优化问题”。确认性适用域限定为：`m >= 3`，图非空且非完全，至少 2 个确定性连通分量，连续窗口的加权 Jaccard 稳定度不低于 0.60。适用域以外只检验回退契约，不宣称受益。

## 2. 输入、输出、变量与流程

### Input

- 冻结候选方法规范：`artifacts/stage5/method_spec_I3_CVGR_v0.1.md`；
- 12 个带已知约束块真值的确定性合成问题规范；
- CEC2006 清单中 16 个 `m >= 3` 的适用域问题与 8 个 `m < 3` 的回退问题；
- 30 个预先生成的公共随机种子；
- 后续需冻结的软件版本、硬件信息、配置与原始日志格式。

### Output

- H1：问题级图恢复 NMI 及其与负对照的配对差；
- H2：问题级主导违反块解析方向导数为负的供体差分比例及配对差；
- H3：问题级 Vargha–Delaney `A12`（CVGR 相对各主要对照的约束优先终值优势概率）；
- H4：回退路径的供体、试验向量、选择、随机数消耗与 FFE 台账逐项一致性；
- 激活率、运行时间开销、失败代码、逐次 FFE 台账、原始运行包与复现清单。

### Process

固定方法与统计契约 → 实现 TDD 绿灯（需后续授权）→ 零 FFE 合成性质测试 → 独立授权机制实验 → 机制门判定 → 独立授权 CEC2006 确认性实验 → 盲化汇总 → 预注册分析 → 证据分级与论文写作资格判断。

### Flow logic

`配置/哈希核验 → 基线回归与 FFE 审计 → 生成公共初始种群和域分离随机流 → 在线图估计 → 激活门 → CVGR 或逐比特回退 → 相同约束比较/选择/记忆更新 → 固定预算停止 → 不可变运行包 → 问题级汇总 → Holm 校正 → success/failure/inconclusive 分支`。

## 3. 方法变量与控制变量

- 自变量：算法变体（CVGR、父算法、度保持重连、种群多样性匹配控制；机制阶段另含标签置换、标量违反、去稳定门）。
- 状态变量：可行性、每约束归一化违反向量、滑动窗口、图边权、连通分量、稳定度、激活码、SHADE 记忆与外部档案。
- 主要因变量：NMI、解析下降方向比例、问题级 A12、回退一致性。
- 控制变量：目标/约束函数、每次评估的 FFE 定义、种群规模、初始化、终止预算、边界修复、选择、参数记忆、档案、基础 RNG 种子、运行环境。
- 已知量：合成问题真值分块、CEC2006 适用域清单、预注册随机种子。
- 待核验量：现代约束基准的许可、规范实现与可复现性；未通过前不得进入确认性主表。

## 4. 假设、estimand 与反证

### H1 图结构恢复

在 12 个合成问题上，以“问题”为统计和分析单位。每个固定检查点若未激活则 NMI 记为 0；问题级值为各固定检查点 NMI 的中位数。CVGR 相对度保持重连与标签置换各形成一组问题级配对差。

- success：CVGR 跨问题中位 NMI `>= 0.60`，对两个负对照的中位配对增量均 `>= 0.20`，且两项单侧精确 Wilcoxon 检验经 Holm 校正均 `q < 0.05`。
- failure：CVGR 中位 NMI `<= 0.30`，或相对任一负对照的中位配对增量 `<= 0`。
- inconclusive：其余情况，包括达到效应阈值但校正后精度不足。

### H2 方向机制

对每个问题，将激活后的有向供体差分投影到预定义的主导违反块解析梯度；方向导数小于 0 记为下降。没有激活事件的问题其比例记为 0，禁止删除。

- success：CVGR 相对度保持重连和多样性匹配控制的下降比例中位配对增量均 `>= 0.05`，且 Holm 校正后均 `q < 0.05`。
- failure：相对任一主要机制控制的中位配对增量 `<= 0`。
- inconclusive：其余情况。

该指标只支持“实现按预定机制改变了方向选择”的操作性解释，不等同于收敛因果证明。

### H3 适用域性能

在 16 个 CEC2006 `m >= 3` 问题上，每个算法使用同一组 30 个公共种子。单次终值按 Deb 式约束优先规则比较：优先可行；均不可行时比较总归一化违反；均可行时比较目标值；容差相等计平局。每个问题对每个比较器计算 A12，种子只用于估计该问题的随机输出分布，推断单位仍为问题。

- success：CVGR 相对父算法、度保持重连和多样性匹配控制的跨问题中位 A12 均 `>= 0.56`，并且针对 `A12 > 0.5` 的三项单侧精确 Wilcoxon 检验经 Holm 校正均 `q < 0.05`；同时 H1、H2 不得处于 failure。
- failure：相对任一主要比较器的跨问题中位 A12 `<= 0.50`，或 H1/H2 任一为 failure。
- inconclusive：其余情况。

`0.56` 是预注册的最小实践效应阈值，不是文献已证明的领域常数；若后续改动必须生成新版本并重新获得作者授权。

### H4 回退等价性

在 8 个 `m < 3` 问题及所有强制回退夹具上，CVGR 包装器必须与父算法在供体索引、试验向量、选择结果、基础 RNG 状态和 FFE 账本上逐项完全一致。任何一个字节级/数值级不一致均触发 `STOP_NO_GO`。通过只说明软件契约成立，不构成性能证据。

## 6. 对照公平性

- 数据：同一问题实现、相同变量边界、约束容差和单次评估返回；
- 计算：相同种群规模和 FFE 上限，图计算不计 FFE但单独报告墙钟开销；
- 调参：主分析不对 CVGR 单独调参；所有共有 SHADE 参数锁为父算法默认值；CVGR 特有阈值按方法规范固定；
- 评测：相同 30 个种子、相同终值比较器、相同失败处理、相同统计脚本；
- 实现：比较器尽量复用同一代码路径；只允许目标机制的一处差异；
- 外部算法：未完成身份、许可、复现与等预算审计前，不进入确认性优势声明。

## 7. 统计分析

- 独立单位：问题；seed 是问题内技术重复。
- 主要汇总：问题级中位数/配对差；报告全部问题散点和区间，不只报告平均名次。
- 检验：预定方向的精确 Wilcoxon signed-rank；同一假设内按主要比较器 Holm 校正。
- 效应量：H1/H2 报告问题级配对差与中位数；H3 报告每问题 A12 和跨问题中位数。
- 零差与并列：使用统计库的冻结实现并在实现锁中记录；不得按结果更换处理规则。
- 缺失/失败：失败运行不得删除。可归因于算法的失败赋最差约束优先结果；基础设施失败按失败码隔离，只有按冻结恢复政策重试一次，仍失败则问题级结果标为缺失并触发无结论门。
- 功效边界：12/16 个问题由现有基准范围决定，没有可靠先验效应分布可支持诚实的传统功效计算。30 seeds 提高问题级分布估计精度，但不增加独立问题数。因此采用固定 N 敏感性阈值和三分支结论，不声称预先达到 80% 功效。

## 8. 验证、确认与风险

### Verification

- 图构造的置换/缩放不变性、非有限值 fail-closed；
- 已知块结构的确定性算术核验；
- 供体索引合法性与反互惠条件；
- 回退逐比特等价；
- 每次目标与全部约束共同返回只计 1 FFE；
- 运行包 hash、配置、seed、版本与台账一致。

### Validation

本项目是算法研究，不涉及物理实验。合成真值只验证机制可识别性；CEC2006 只提供计算基准上的外部效度。两者都不能验证工业机械系统的物理有效性。若论文要扩展至机器人/结构优化应用，必须另建高保真模型与独立工程验证计划。

### 主要 kill criteria

- H1 中位 NMI `<= 0.30`；
- 超过一半适用域问题的激活率 `< 20%`；
- H2 相对度控制或多样性控制无正向实践效应；
- 图机制墙钟开销中位数 `> 25%`；
- 任一 FFE 记账不等或强制回退不一致；
- 现代基准的许可/身份问题被掩盖或把探索性结果写成确认性结果。

## 9. 论文资格门
