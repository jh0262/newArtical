# PADE补充实验问题库

此文件只统一评价接口，未改变两份原源码的函数表达式、维度、变量界限或工程模型常数。原文件保留。公共接口为 `probs = pade_problems()`，返回26个问题：F01—F23、WB、CB、PV；每个问题均支持 `[f, cv] = prob.eval(x)`，且接受行向量或列向量，内部统一为行向量。

## 接口与约束

- 字段固定为 `id,name,D,lb,ub,discrete_idx,discrete_step,eval`。
- F01—F23无工程不等式约束，`cv=0`；变量界限由优化器统一处理。
- WB/CB/PV沿用原始 `cv = sum(max(g_i,0))`，`g_i<=0`为可行。这里是原始残差和，未作量纲归一化；不同问题之间不能比较CV绝对大小。可行判定容差应由统一求解器显式设置。
- 评价函数不自动截断边界、不自动取整、不自动加罚。优化器负责同一套边界修复、离散网格投影与Deb选择，保证比较时模型相同。
- PV的第1、2变量为0.0625网格，`discrete_idx=[1,2]`，其余问题的离散字段为空。
- F07每一次评价都调用一次 `rand()` 加入[0,1)均匀噪声；噪声消耗应包含在随机种子/评价复现设计中，不应把其结果当成确定性函数最小值。
- F15在分母为零的输入上可能出现非有限数。求解器应把非有限评价记为无效候选，同时计入一次函数评价，不能静默重采样免计FE。

## 保留的特殊常数

F15按原实际数据运行，命名为“Kowalik-type fit (source constants)”，保留：

```matlab
aK = [0.1957,0.1947,0.1735,0.1600,0.1472,0.1392,0.1320,0.1287,0.1235,0.1190,0.1180];
bK = 1 ./ [0.25,0.5,1,2,4,6,8,10,12,14,16];
```

不能将经典Kowalik数据的0.0003075直接认定为此数据实例的已知最优值。公共问题结构不暴露原源码中的 `f_opt`，避免错误地利用该参考值统计误差。F01—F23函数与原实现一致，不将其命名为CEC官方测试集。

PV封头厚度约束保留 `0.0095*R - Th <= 0`，没有改成其他文献常见的0.00954。PV的半径上限/长度上限均为200，长度约束还保留原 `L-240<=0`，在本变量界限内冗余。

## 工程变量和单位约定

| ID | 变量顺序 | 原模型单位/解释 |
|---|---|---|
| WB | `[h,l,t,b]` | 长度按英寸，载荷6000 lbf，跨度14 in，E=30e6 psi、G=12e6 psi，剪应力与正应力为psi，挠度为in；目标为原基准成本函数。 |
| CB | 五段截面尺寸 `[x1,...,x5]` | 保留原无量纲化设计基准：目标 `0.0624*sum(x)`、挠度残差 `sum([61,37,19,7,1]./x.^3)-1`。原源码未独立给出完整单位推导，不能将该数值擅自标为kg或SI长度。 |
| PV | `[Ts,Th,R,L]` | 厚度、半径和圆柱段长度按in，容积约束1296000 in^3；R是半径，目标为原基准制造成本函数。 |
